# Q&A Educational - Site de Întrebări și Răspunsuri

Un site educațional cu întrebări interesante și răspunsuri simple, pentru toate vârstele.

## Caracteristici
- 🧠 **50+ întrebări educaționale** cu răspunsuri complete
- 👶 **Pentru copii și adulți** - Explicații simple pentru toată lumea
- 🎲 **Random Question** - Descoperă întrebări aleatoare
- 📊 **Statistici vizuale** - Grafice cu distribuția pe categorii
- 📄 **Export PDF** - Descarcă toate întrebările
- 🌙 **Dark/Light Theme** - Comutare între teme
- 🔍 **Căutare** - Găsește rapid întrebări
- 🏷️ **Filtre** - Pe categorii

## Tehnologii
- HTML/CSS/JS pur (fără framework-uri)
- DeepSeek API pentru generare conținut
- Chart.js pentru grafice
- jsPDF pentru export PDF
- GitHub Pages pentru hosting
